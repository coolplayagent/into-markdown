正式版 0.0.6 成功交付的 49 篇关闭 OCR 论文共 1,009 页，独立原生文字 12 字符片段召回均值由 72.76% 提高到 98.06%。该指标用于文字保留检查；阅读顺序、表格关系和上下标另有固定布局回归。100 篇关闭 OCR 输出在公共策略修复间逐篇哈希一致；无损 PNG 改动后再逐篇对照完整正文与解码后的可见像素，详见 pdf-compression-comparison.json。

跨格式补充对照使用两版相同的显式 4 GiB 预算：0.0.6 成功 155/207，候选成功 207/207；137 份词序直接一致，18 份差异逐项复核，其中发现的空白附件标签已修复。10 本 EPUB 去除各自生成的恢复提示后，全部正文词序一致；ZIP 内 PDF 的 163 个源词经独立 pdftotext 提取核对，全部保留。该补充对照与默认配置交付验收分别记录。

真实 Web/CLI 一致性共 26 组比较：12 组公共语料、6 组附件标签复测、8 组当前候选的必选论文、邮件、Word 与软遮罩 PDF；检查正文、资产哈希与 OCR 计数。
